# 🎬 CineComment

CineComment is a simple movie comment web application built with Vite and React.
Users can submit comments and reviews about movies via a clean and minimal form.

## Features
- Movie comment submission
- Real-time comment display
- Built with Vite + React
- Clean and scalable project structure

## Tech Stack
- Vite
- React
- JavaScript

## Getting Started
```bash
npm install
npm run dev
